# MINER'S ADVENTURE

A Minecraft mod I made for Minecraft 1.21 using Forge.

Miner's Adventure adds some new ores, items, tools and armor to the game. I mainly made it because I wanted to try making my own Minecraft mod and add some things that I would like to use while playing survival.

---

## About

The main idea of the mod is to make mining and survival a little more interesting.

You can find Ruby Ore underground and get Ruby from it. Ruby and Sapphire can then be used to make different tools, armor and other items.

There is also a special Sapphire Extreme tool that I made with very high mining speed and attack damage. It also has a special ability that lets the player move through water or rain.

## Tools

The mod has Ruby and Sapphire versions of:

* Pickaxe
* Axe
* Sword
* Shovel
* Hoe

The Sapphire Extreme is a special tool with very high mining speed and damage.

---

## Armor

Ruby and Sapphire armor sets are included in the mod.

The Ruby Helmet gives the player Night Vision while wearing it.

The Ruby Boots reduce fall damage.

---

## Sapphire Extreme

The Sapphire Extreme is one of the special items in the mod.

It can mine blocks very quickly and has high attack damage. It can also be used to move quickly through water or rain.
